# 丹青取色

从古画里，取一抹中国传统色。

上传一幅古画或任意图片，自动提取画面主色，在 526 种中国传统色里找到最贴近的名字，存成色卡图，或导出成 CSS 变量。比如《千里江山图》里能取出蟹壳灰、鲛青、田螺绿，《富春山居图》取出来全是各种灰——水墨画本来就没有彩色。

**在线使用：https://cchichi.github.io/danqing-palette/**（纯前端，图片不上传服务器）

![色卡海报](docs/poster.png)

## 功能

- 拖拽、Ctrl+V 粘贴或点击上传；内置《千里江山图》《富春山居图》《瑞鹤图》《溪山行旅图》四幅示例，均为公有领域藏品照片，base64 内嵌，双击 index.html 断网也能用
- 色块右上角的小圆点是画面的原始色，旁边是它对应的传统色名，能看出「画里的颜色」和「色卡名字」差多少
- 部分色名附一句注解：有把握出处的给出处（靛青、姚黄魏紫、景泰蓝……），给不了的只写一句释义，宁缺毋滥
- 色卡海报三种尺寸：朋友圈 1080×1620、手机壁纸 1080×2340、方图 1080×1080
- 导出 CSS 变量（`--蟹壳灰: #695e45;` 中文变量名合法且好记）和 JSON
- 固定随机种子，同一张图每次取色结果一致

![使用界面](docs/screenshot-result.png)

## 原理

1. 图片缩到最长边 260px，收集不透明像素；
2. k-means++（k=8，固定种子）迭代出主要色簇，CIELAB 色差小于 5 的簇合并，保留占比前 6 的颜色；
3. 每一簇在 CIELAB 空间用 CIE94 公式对 526 种传统色做独占最近邻匹配：按占比从大到小依次认领，同名时自动让给次近的色，保证色名不重复；
4. 色卡海报用 Canvas 2D 绘制导出。

全部代码无依赖、无构建，`index.html` 加原生 JS，共约 800 行。

## 本地运行

无需构建，任选其一：

```bash
# 直接双击 index.html 也可以
npx serve .
# 或
python -m http.server
```

## 数据与图片来源

- 中国传统色数据（526 色）：[zhongguose.com 中国传统色手册](https://zhongguose.com)
- 色名注解为人工整理，目前约 40 条，见 [js/notes.js](js/notes.js)，欢迎补充修正
- 示例画作：Wikimedia Commons 公有领域藏品照片——王希孟《千里江山图》、黄公望《富春山居图》（剩山图）、赵佶《瑞鹤图》、范宽《溪山行旅图》
- 灵感：《中国传统色》系列图书与「中国色」网站
